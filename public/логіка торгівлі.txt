1. ФІЛОСОФІЯ ТА ФУНДАМЕНТАЛЬНА КОНЦЕПЦІЯ ТРЕЙДЕРА DEMENTOR
--------------------------------------------------------------------------------
Головне правило Dementor: "Більшість трейдерів грають на емоціях і надіях, маркет-мейкер
грає на страху, а системний трейдер грає на ймовірностях та об'єктивних даних".

Ринок рухається НЕ за лініями тренду чи фігурами "голова і плечі", а за ліквідністю:
- Ринок рухається від одного ліквідного пулу (де стоять стоп-лоси натовпу) до іншого.
- Ціну штовхають РИНКОВІ ордери (Market Orders).
- Ціну зупиняють ЛІМІТНІ ордери (Limit Orders / Icebergs), які поглинають ринковий тиск (Absorption).
- Звичайний свічковий графік приховує те, що відбувається всередині свічки. Кластерний
  аналіз (Footprint) показує реальний бій між покупцями (Ask) і продавцями (Bid).


2. СЕКРЕТ ТОРГОВОГО АЛГОРИТМУ
--------------------------------------------------------------------------------
Алгоритм автора базується на чіткому ланцюжку 5 обов'язкових кроків:

  [1. HTF Контекст] -> [2. Зняття ліквідності] -> [3. Кластерна реакція] -> [4. Підтвердження дельтою] -> [5. Вхід на ретесті]

1) Визначення зони інтересу (POI) на старшому ТФ (1D, 4H, 1H):
   - Межі Value Area минулого дня/тижня (VAH, VAL).
   - Незакритий Naked POC (рівень максимального непротестованого об'єму).
   - Геп на графіку ф'ючерсів CME.
   - Рівень пулу ліквідності (Equal Highs / Equal Lows).

2) Маніпуляція та зняття ліквідності (Sweep):
   - Ціна виходить за ключовий локальний максимум або мінімум, активуючи стоп-лоси та втягуючи FOMO-ритейл у пробій.

3) Поглинання (Absorption) на Footprint:
   - У хвості свічки (тіні) виникають аномально високі кластери.
   - Наприклад, на максимумі свічки проходять величезні покупки (Ask), але ціна НЕ йде вгору і закривається нижче рівня. Це означає, що лімітний продавець поглинув усі ринкові покупки.

4) Розбіжність ціни та кумулятивної дельти (CVD Divergence):
   - Ціна оновлює хай, а кумулятивна дельта падає (або навпаки).
   - Або дельта різко червоніє при спробі пробою вгору.

5) Вхід у позицію:
   - Вхід здійснюється НЕ "в лоб" під час пробою, а після повернення ціни в діапазон (Acceptance back into Value Area) або на дзеркальному ретесті POC/локального зламу структури на 5m/1m.


3. МУЛЬТИТАЙМФРЕЙМОВА СТРУКТУРА (HTF -> MTF -> LTF)
--------------------------------------------------------------------------------
Dementor наголошує: ніколи не торгуйте 1m або 5m графік у вакуумі. Кожен таймфрейм має свою чітку роль:

+--------------------+---------------------------------------------------------------+
| Таймфрейм          | Що саме дивиться трейдер                                      |
+--------------------+---------------------------------------------------------------+
| Daily (1D)         | - Глобальний тренд та фаза ринку (баланс чи дисбаланс/тренд)  |
|                    | - Тижневий і місячний профіль об'єму (Weekly POC, VAH, VAL)  |
|                    | - Гепи на ф'ючерсах CME (BTC1!, ETH1!)                        |
|                    | - Глобальні непротестовані Naked POC                          |
+--------------------+---------------------------------------------------------------+
| 4-годинний (4H)    | - Основні структурні swing хаї та лої                         |
|                    | - Сесійні діапазони попередніх днів                           |
|                    | - Рівні відкритого інтересу (Open Interest)                   |
+--------------------+---------------------------------------------------------------+
| 1-годинний (1H)    | - Внутрішньоденний профіль об'єму (Daily Profile)             |
|                    | - Азійський сесійний діапазон (Asia High/Low)                |
|                    | - Зони дисбалансу (Single Prints / LVN)                       |
+--------------------+---------------------------------------------------------------+
| 15m / 5m           | - Структура поточної торговельної сесії (Лондон, Нью-Йорк)   |
|                    | - Момент зняття ліквідності (Sweep)                           |
|                    | - Дивергенції на Кумулятивній Дельті (CVD)                   |
+--------------------+---------------------------------------------------------------+
| 5m / 1m (Footprint)| - Виконання угоди (Execution): кластери Bid/Ask              |
|                    | - Stacked Imbalances (стек дисбалансів від 300%+)             |
|                    | - Захист лімітних рівнів та розворотні патерни свічок         |
+--------------------+---------------------------------------------------------------+


4. ПОВНИЙ СТЕК ІНДИКАТОРІВ ТА ЇХ ТОЧНІ НАЛАШТУВАННЯ
--------------------------------------------------------------------------------
Dementor не використовує запізнілі стандартні індикатори на зразок RSI, MACD або
Stochastic. Замість цього застосовується аналітика потоку ордерів (Order Flow):

1) Профіль об'єму (Volume Profile / Market Profile / TPO):
   - Період: Daily (по днях) та Session (по торгових сесіях).
   - Value Area Percentage: 68.2% або 70% (одне стандартне відхилення нормального розподілу).
   - Відображення рівнів:
     * POC (Point of Control) — яскравіший колір (жовтий або червоний).
     * VAH (Value Area High) — верхня межа справедливої ціни (синій/зелений).
     * VAL (Value Area Low) — нижня межа справедливої ціни (синій/зелений).
     * Developing POC / Developing Value Area — динамічний розвиток протягом дня.
     * Naked POC (nPOC / Virgin POC) — подовжувати променем вправо до моменту першого дотику ціною.

2) Кумулятивна об'ємна дельта (Cumulative Volume Delta / CVD):
   - Розрахунок: Різниця між об'ємом за ринковими покупками (Ask) та ринковими продажами (Bid).
   - Формула бару: Delta = Volume(Ask) - Volume(Bid).
   - Cumulative Delta = Сума дельти від початку торгової сесії.
   - Відображається у вигляді окремого підграфіку (лінійного або свічкового).

3) Кластерний графік (Footprint / Cluster Chart):
   - Тип: Bid x Ask або Delta Clusters.
   - Imbalance Ratio (коефіцієнт дисбалансу): 3:1 (300%) або 4:1 (400%). Тобто, якщо на Ask стоїть 300 контрактів, а на Bid по діагоналі всього 75 — кластер підсвічується зеленим як домінування агресивного покупця.
   - Stacked Imbalances: мінімум 3 поспіль дисбаланси на суміжних цінових рівнях в одній свічці.
   - Cluster Filter (фільтр великих блоків): динамічний фільтр для BTC (наприклад, кластери > 50-100 BTC виділяються яскравою рамкою).

4) CME Bitcoin & Ether Futures (BTC1!, ETH1!):
   - Відображення п'ятничного закриття о 23:00 GMT та недільного відкриття.
   - CME Gaps відмічаються горизонтальними прямокутниками до повного заповнення (Fill).


5. ДЕТАЛЬНИЙ РОЗБІР ІНСТРУМЕНТІВ АНАЛІЗУ
--------------------------------------------------------------------------------
5.1. Ринковий профіль (Market Profile) та теорія аукціону
Ринковий рух — це безперервний двосторонній аукціон з пошуку справедливої ціни.
- Баланс (Range / Chop): ціна коливається всередині Value Area (між VAL і VAH). У цьому стані 80% часу ринок ротується навколо POC. Стратегія: купувати від VAL з ціллю POC/VAH, або продавати від VAH з ціллю POC/VAL.
- Дисбаланс (Trend): ціна виходить за межі Value Area з великим об'ємом та дельтою. У цьому випадку VAH/VAL виступають підтримкою/опором для продовження імпульсу.

5.2. Naked POC (Непротестована точка контролю)
Коли день закінчується, а його найторгованіший рівень (POC) наступного дня або кількох днів не тестується — він стає Naked POC.
Чому це працює: на цьому рівні зосереджений найбільший капітал великих учасників. Це найсильніший магніт ліквідності. Коли ціна повертається до nPOC, з імовірністю понад 75% відбувається реакція (відбій або консолідація).

5.3. Дивергенція кумулятивної дельти (CVD Divergence)
Це один з найсильніших сигналів Dementor:
- Ведмежа дивергенція (Bearish Divergence):
  Ціна робить новий Higher High (вищий максимум), а CVD робить Lower High (нижчий максимум).
  Пояснення: Ціна оновлює хай за інерцією або стопами, але в ринку вже НЕМАЄ реальних ринкових покупців. Ринок виснажений, великий гравець закриває позиції об ритейл.
- Бичача дивергенція (Bullish Divergence):
  Ціна робить новий Lower Low (нижчий мінімум), а CVD робить Higher Low (вищий мінімум).
  Пояснення: Ринкові продавці продають з панікою, але ціна не падає, бо лімітний покупець повністю викуповує всі продажі (Абсорбція).

5.4. Кластери свічки (Footprint) та Аномалії на краях свічок
Звертайте увагу на кінці тіней:
- Якщо на самому піку верхньої тіні свічки утворюється зелений кластер великого об'єму (покупки), але свічка закривається червоною і з довгою тінню зверху — це 100% сигнал Поглинання (Trapped Buyers). Покупці потрапили в пастку. Їхні стопи стануть паливом для падіння.
- Якщо на самому дні нижньої тіні виникає великий червоний кластер (продажі), але свічка викуповується вгору — це Trapped Sellers (продавці в пастці).


6. 4 КЛЮЧОВІ ТОРГОВІ СЕТАПИ ТРЕЙДЕРА DEMENTOR
--------------------------------------------------------------------------------

========================= СЕТАП 1: LIQUIDITY SWEEP & FOOTPRINT ABSORPTION =========================
Ідея: Зняття полиці ліквідності над/під важливим рівнем з моментальним поглинанням.

СХЕМА НА ГРАФІКУ:
       [Свічка маніпуляції]
              ▲
             / \  <-- Тінь знімає максимум (Sweep EQH)
            |   | <-- На піку тіні Footprint показує величезний зелений кластер (Trapped Buyers)
            |   |
         ---|---|--- Ключовий рівень опору / EQH
            |   |
            \ _ / <-- Тіло свічки закривається ПІД рівнем!
              |
              ▼
    [Наступна свічка: ретест рівня знизу] ---> ТОЧКА ВХОДУ В SHORT

УМОВИ ВХОДУ (SHORT):
1. На 1H/4H визначено пул ліквідності: рівні максимуми (EQH) або локальний High попереднього дня.
2. Ціна імпульсно пробиває хай (ритейл купує пробій, шортисти ловлять стопи).
3. На 5m або 1m графіку свічка залишає довгу тінь зверху (> 50% розміру свічки).
4. У Footprint на верхньому краї свічки видно максимальний об'єм за покупками (Ask > 300% Bid), але свічка закривається ЧЕРВОНОЮ.
5. Дельта свічки або від'ємна, або різко впала порівняно з попередніми.
6. ВХІД: лімітним або ринковим ордером при поверненні ціни під рівень зняття або на ретесті нижньої межі пробою.
7. СТОП-ЛОС: за екстремум тіні свічки зняття ліквідності (+ невеликий буфер на спред).
8. ТЕЙК-ПРОФІТ:
   - TP1 (40% позиції): найближчий внутрішньоденний POC або Value Area High. Після TP1 стоп переводиться в БЕЗЗБИТОК (Breakeven).
   - TP2 (30% позиції): середини денного діапазону (POC дня).
   - TP3 (30% позиції): протилежний пул ліквідності (протилежні рівні лої / VAL дня).


========================= СЕТАП 2: VALUE AREA ROTATION (ПОВЕРНЕННЯ В БАЛАНС) =========================
Ідея: Хибний вихід за межі вартості (Deviation) та рух через увесь профіль від VAL до VAH або навпаки.

СХЕМА НА ГРАФІКУ:
   VAH ---------------------------------------------------- [Ціль TP2]
         \          /
          \        /  (Рух через центр балансу)
   POC  ----\------/--------------------------------------- [Ціль TP1]
             \    /
   VAL -------|--/-----------------------------------------
              | /    <-- Хибний вихід (Deviation)
              ▼
           [Sweep під VAL, поглинання, повернення в Value Area] ---> ТОЧКА ВХОДУ В LONG

УМОВИ ВХОДУ (LONG):
1. Ринок перебуває у флеті/боковику (Balanced Market). Побудовано Value Area попереднього дня або тижня.
2. Ціна випадає нижче VAL (Value Area Low).
3. На випаданні немає закріплення: наступні 1-2 свічки повертають ціну всередину Value Area (Acceptance).
4. CVD показує бичачу дивергенцію (ціна оновила лой, дельта вища за попередній лой).
5. ВХІД: у момент закриття свічки 5m назад всередині Value Area або лімітним ордером на ретесті VAL зверху.
6. СТОП-ЛОС: за мінімум виходу (Deviation Low).
7. ТЕЙК-ПРОФІТ:
   - TP1 (50%): Point of Control (POC) діапазону.
   - TP2 (50%): протилежна межа Value Area High (VAH).
   - R:R у цьому сетапі зазвичай становить від 1:3 до 1:5.


========================= СЕТАП 3: CME GAP FILL + NAKED POC RETEST =========================
Ідея: Використання магніту ліквідності та балансування розриву котирувань ф'ючерсів Чиказької біржі (CME).

УМОВИ ВХОДУ:
1. На вихідних на крипторинку відбувся рух, унаслідок чого на графіку ф'ючерсів CME (BTC1!) утворився розрив (Gap).
2. На початку тижня (понеділок-вівторок) ціна рухається в бік гепу для його повного закриття.
3. Усередині або на межі гепу знаходиться непротестований рівень Naked POC минулих періодів.
4. Дотик до межі гепу / nPOC супроводжується різким скороченням волатильності та появою кластерного айсберг-захисту на Footprint.
5. ВХІД: при реакції на рівень гепу в напрямку відбою від нього (або робота в шорт/лонг до повного закриття гепу як цілі).
6. СТОП-ЛОС: за локальний структурний екстремум перед перекриттям гепу.
7. ТЕЙК-ПРОФІТ: найближчий протилежний POC або зона дисбалансу (Single Prints).


========================= СЕТАП 4: CUMULATIVE DELTA DIVERGENCE + STRUCTURE BREAK (CHoCH) =========================
Ідея: Системний розворот тенденції на основі виснаження ринкових ордерів.

УМОВИ ВХОДУ (SHORT):
1. Ціна формує Higher High на 15m/5m графіку.
2. Кумулятивна дельта (CVD) формує виразний Lower High.
3. Відбувається злам локальної структури (Change of Character / CHoCH) — свічка імпульсно тілом закривається нижче останнього висхідного свингу (Higher Low).
4. На Footprint видно формування Stacked Selling Imbalances (мінімум 3 рівні агресивних продажів).
5. ВХІД: на ретесті рівня зламаної структури або на ретесті POC імпульсної пробійної свічки.
6. СТОП-ЛОС: за локальний максимум свічки зняття.
7. ТЕЙК-ПРОФІТ: динамічний трейлінг-стоп або фіксація на ключових пулах ліквідності внизу.


7. ПОМИЛКА №1, ЧЕРЕЗ ЯКУ ВТРАЧАЮТЬ ДЕПОЗИТ (РОЗБІР ВІДЕО)
--------------------------------------------------------------------------------
У своєму відео "Одна помилка, через яку більшість втрачає все!" Dementor розбирає головного вбивцю депозитів:
- Це НЕ неправильний технічний аналіз.
- Головна помилка — УСЕРЕДНЕННЯ ЗБИТКОВОЇ ПОЗИЦІЇ БЕЗ СТОП-ЛОСУ (Martingale / Доливка в мінус).

Чому трейдери це роблять:
Трейдер входить у лонг, ціна йде вниз. Замість визнання неправоти та отримання розрахованого стопу в 1%, трейдер думає: "Ціна стала вигіднішою, куплю ще, середня ціна буде кращою".
Коли ринок переходить у фазу трендового дисбалансу, він може рухатися без відкату сотні пунктів. У підсумку одна угода знищує 50-100% усього депозиту!

Залізні закони Dementor:
1. СТОП-ЛОС ВИСТАВЛЯЄТЬСЯ ЗАВЖДИ В МОМЕНТ ВХОДУ В УГОДУ. Жодних ментальних стопів у голові!
2. НІКОЛИ НЕ ВІДДАЛЯТИ СТОП-ЛОС. Якщо ціна наближається до стопу, ви зобов'язані прийняти системний збиток.
3. НІКОЛИ НЕ ДОЛИВАТИСЯ В МІНУСОВУ ПОЗИЦІЮ. Доливатися (пірамідити) дозволено ТІЛЬКИ в прибуткову позицію, коли стоп уже переведено в беззбиток!


8. ПСИХОЛОГІЯ ТА ПОДОЛАННЯ FOMO (Fear Of Missing Out)
--------------------------------------------------------------------------------
Звідки береться страх упущеної вигоди (відео Dementor "FOMO"):
- Бажання наздогнати зелену/червону свічку, що летить без вас.
- Порівняння себе з успіхами інших людей у Telegram/Instagram.
- Жадібність та бажання швидко помножити капітал.

Як боротися з FOMO за алгоритмом Dementor:
1. Правило "Потяг пішов — чекай наступний": якщо імпульс уже відбувся без вашого тригера входу, входити КАТЕГОРИЧНО ЗАБОРОНЕНО. Вхід на піку імпульсу гарантовано дає найгірший R:R і ловить відкат прямо в ваш стоп.
2. Прописаний чек-лист: поки хоча б 1 пункт з вашого алгоритму не виконано — ви не маєте права натиснути кнопку "Buy" або "Sell".
3. Мислення дистанцією: ваш дохід формується не за одну угоду, а за серію з 100 угод за системою. Окремо взята пропущена угода дорівнює нулю і ніяк не шкодить депозиту.


9. МАТЕМАТИКА РИЗИК-МЕНЕДЖМЕНТУ, МАРЖІ ТА КРЕДИТНОГО ПЛЕЧА
--------------------------------------------------------------------------------
Як насправді працює маржа і плече (розбір відео Dementor):
Більшість новачків вважають, що 50x або 100x плече — це гарантований злив або гарантоване багатство.
Dementor пояснює: плече — це лише інструмент регулювання маржинального забезпечення.
Важливий ТІЛЬКИ ВАШ РИЗИК У ДОЛАРАХ ВІД РОЗМІРУ ДЕПОЗИТУ!

Формула розрахунку розміру позиції:
  Ризик на угоду ($) = Депозит ($) * Ризик (%)
  Відстань до стоп-лосу (%) = |Ціна входу - Ціна стоп-лосу| / Ціна входу * 100
  Розмір позиції ($) = Ризик на угоду ($) / (Відстань до стоп-лосу (%) / 100)

Приклад:
- Депозит: $10,000.
- Базовий ризик на угоду: 1% = $100.
- Ціна входу в BTC: $65,000.
- Системний стоп-лос за хай зняття: $65,650 (відстань = 1.0%).
- Розмір позиції = $100 / 0.01 = $10,000 (тобто рівно 1x плече або 0.1538 BTC).
- Якщо відстань до стопу всього 0.5% ($65,325):
  Розмір позиції = $100 / 0.005 = $20,000 (тобто 2x плече).
Висновок: Плече автоматично розраховується від відстані до стопу, а НЕ виставляється випадковим чином!

Правило співвідношення ризику до прибутку (Risk to Reward / R:R):
- Мінімальний допустимий R:R для входу = 1:2.5.
- Стандартний робочий R:R = 1:3 - 1:5.
- При вінрейті навіть у 40% з R:R 1:3 ваша торгова система генерує стабільний чистий прибуток на дистанції!
